AI-powered marketing content generation for WordPress. Create engaging blog posts, social media content, and marketing copy effortlessly.

== Description ==

Marketing AI brings the power of artificial intelligence to your WordPress site, enabling you to generate high-quality marketing content with just a few clicks.

= Features =

* **AI Content Generation** - Create blog posts, social media content, and marketing copy
* **Gutenberg Block** - Generate content directly in the block editor
* **Classic Editor Support** - Works with the classic editor too
* **Business Context** - Automatically detects your site's context for personalized content
* **Multiple Tones** - Professional, casual, friendly, authoritative, and more
* **SEO Optimized** - Generated content is optimized for search engines
* **Bulk Generation** - Create multiple pieces of content at once
* **Usage Dashboard** - Track your content generation and API usage

= How It Works =

1. Install and activate the plugin
2. Enter your Marketing AI API key in settings
3. The plugin automatically detects your site's business context
4. Start generating content from the post editor or bulk generator

= Premium Features =

Upgrade to Premium for:
* Unlimited content generation
* Advanced content types
* Priority support
* Custom branding options
* API rate limit increases

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/marketing-ai/`
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Go to Marketing AI > Settings to configure your API key
4. Start generating content!

== Frequently Asked Questions ==

= Do I need an API key? =

Yes, you need a Marketing AI API key. You can get one by signing up at https://marketingai.com

= What content types can I generate? =

Blog posts, social media posts (Instagram, LinkedIn, Twitter), marketing copy, and more.

Yes! We have a custom Gutenberg block for seamless integration.
